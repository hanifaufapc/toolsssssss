Cara pakai: buka portal dengan 2 tangan — ujung jempol + telunjuk kedua tangan jadi 4 titik membentuk bangun datar; di dalamnya efek filter mengikuti gerakan. Alat Musik

Virtual piano & drum — main, rekam, atau autoplay mengikuti audio.

Vol
C3–E5

Melodi (Piano/Gitar/Bass/Organ/Flute): baris bawah Z X C V B N M , . / = C3–E4, baris atas Q W E R T Y U I O P = C4–E5, tombol hitam S D G H J & 2 3 5 6 7. Shift + tombol = 1 oktaf lebih tinggi (works di semua layout keyboard), tombol + / − geser oktaf piano. Sustain = nada tidak langsung berhenti. Rekam lalu Putar untuk memutar kembali permainanmu. Drum: 1 kick, 2 snare, 3 hi-hat, 4 crash, 5/6/7 tom. Autoplay: pilih file audio/video atau tempel link YouTube — alat musik bermain sendiri mengikuti musiknya (audio asli tidak ikut diputar). Klik di area instrumen dulu jika keyboard tidak merespons.

Downloader

Unduh video dari YouTube, TikTok & Instagram Reels — kualitas terbaik, sepenuhnya di browser.

Cara pakai: tempel link video (YouTube / TikTok / Reels) → Analisis → pilih kualitas → ⬇ Unduh. YouTube: gabungan video+audio terbaik (butuh koneksi internet & halaman via http/https; jika gagal, otomatis pakai format 720p satu file). TikTok: tanpa watermark (HD bila tersedia). Instagram: langsung ambil dari halaman publik. Semua diproses di browser — tidak ada server, file tidak disimpan di mana pun.

Visual Trip

Replay perjalanan di peta — dari titik asal ke tujuan, diikuti mobil.

00:00 / 00:00

Cara pakai: ketik tempat asal dan tujuan (mis. "Surabaya" dan "Bali") lalu Cari Rute — peta menampilkan rute berkendara (OpenStreetMap + OSRM). Pilih kendaraan (mobil balap / taksi / van / bus / motor / kart / pesawat) dan model 3D Kartun atau Ikon 2D, tekan ▶ Putar untuk melihatnya berjalan dari asal ke tujuan; atur kecepatan 0.5×–8× atau seret slider untuk melompat. Atau klik langsung di peta: klik pertama = asal, klik kedua = tujuan. Tekan ⇄ untuk menukar arah, Unduh Video untuk menyimpan replay, Unduh Gambar untuk snapshot peta. Butuh koneksi internet untuk peta & pencarian tempat. Kendaraan 3D oleh Kenney (CC0) & Poly by Google (CC-BY 3.0).

Proteksi File

Kunci file apa pun dengan password — AES-256-GCM sepenuhnya di browser.

🔒 Kunci File
🔓 Buka File

Cara pakai: pilih satu atau banyak file → ketik password 2× → Kunci. File keluar bernama file.plock — enkripsi AES-256-GCM dengan kunci PBKDF2 (310.000 iterasi), password tidak pernah disimpan di mana pun. Untuk membuka: pilih file .plock → ketik password → Buka → unduh/preview isinya. Catatan penting: password yang lupa tidak bisa dipulihkan — simpan dengan baik!
