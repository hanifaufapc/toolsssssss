# AGENTS.md

Static single-page site ("PERKAKAS", https://perkakas.id). No build, test, or lint tooling — `index.html` is the entire app and the only file.

## index.html structure

- **SPA dua view**: `#homeView` (hero + grid tool dari `TOOLS`) dan `#toolView` (bar + `#toolBody`). Router `route()` berdasar `location.hash`: `#/` = home, `#/tool/<key>` = halaman tool. `showTool()` memindahkan panel aktif dari `#panelStore` (storage tersembunyi) ke `#toolBody` — **hanya 1 panel di DOM view aktif** (tidak bertumpuk, anti-lag); `showHome()` mengembalikan panel. Hook keluar: `window.__camStop` (webcam, = klik stop) & `window.__musikStop` (= `stopAuto`) dipanggil saat meninggalkan tool supaya stream/rAF/AudioContext berhenti. UI tool sengaja besar: `.panel` max-width 1180px, padding 36px.
- Panels are matched by `data-panel` key. Add a tool by adding a panel div + entry in `TOOLS`. Twelve tools (IIFE ke-12 = **Downloader Media** tab YouTube/TikTok/IG dari panel `#panelDownload`): kompres, resize, konversi, palet, qr, webcam, musik, editor, viz, trip, protect. Grid CSS pakai `auto-fit,minmax(230px,1fr)`.
- **Downloader IG Reels** (tab `dlIg`, IIFE ke-12): endpoint `?__a=1` / `__d=dis` MATI untuk akses anonim, dan semua API pihak ketiga (cobalt.tools, instagrab.app, igdownloader.app, dll) sudah mati/diblokir. **Satu-satunya cara yang berfungsi**: fetch `https://r.jina.ai/<ig-url>` dengan header `X-Return-Format: html` (CORS OK — r.jina.ai echo `access-control-allow-origin` + izinkan `x-return-format` di preflight). Parsing: regex `"video_versions":\[([^\]]*)\]` → `JSON.parse('['+blok+']')` → ambil entri pertama (urutan kualitas terbaik dulu); caption dari `"caption":{"text":"…"}` (JSON-escaped), author dari awalan `og:description` (`12K likes, X comments - <user> on …`), thumb dari `og:image`. Video CDN `scontent*.cdninstagram.com` kirim `Access-Control-Allow-Origin: *` → download langsung tanpa proxy. Jangan kembalikan `cobalt()` — sudah dihapus. Jina punya rate limit (~20 req/menit) → error "menolak akses anonim" bisa berarti kena limit; pesannya sudah mengarahkan user coba lagi nanti.
- `filePreviewEl(file)` (shared helper) renders image/video/audio/file chip previews; the kompres/konversi/resize panels all show one after a file is picked.
- Webcam tool: in-browser real-time hand tracking via MediaPipe Tasks Vision WASM. **Self-hosted** di `vendor/tasks-vision/` (vision_bundle.mjs + wasm/ + hand_landmarker.task + selfie_segmenter.tflite) karena `@mediapipe/tasks-vision@0.10.14` TIDAK punya `vision_bundle.js` (hanya `.mjs`/`.cjs`) dan CDN jsdelivr/unpkg kerap diblokir ISP Indonesia. `loadHands()` memakai dynamic `import()` ESM: sumber lokal dulu, lalu CDN mirror; model GPU → CPU → CDN fallback. **PENTING: `FilesetResolver.forVisionTasks()` harus di-`await`** — melempar Promise mentah ke `createFromOptions` menghasilkan `ModuleFactory not set` / `Cannot read properties of undefined (reading 'toString')`. Detections run throttled (~25fps) in the existing rAF loop (`draw()`). **Tidak ada HUD skeleton** — landmark tidak digambar. Interaksi ("portal", gaya Retrolens `GedeAnanda/python-handtrack`): dengan **2 tangan**, ujung jempol (lm[4]) + telunjuk (lm[8]) kedua tangan jadi 4 titik → portal segi empat berurutan top-left→top-right→bottom-right→bottom-left (split Y dulu, lalu sort X tiap pasangan — `quadFromHands`), digambar mengikuti tangan dalam transform mirror canvas (outline putih + glow, lingkaran kuning r8 di 4 titik, partikel glow acak 5/tepi, label `PORTAL: <nama>` di dekat sudut kiri-atas digambar di ruang layar non-mirror via `setTransform(1,0,0,1,0,0)`). Di dalam portal (via `ctx.clip()`) efek aktif di-render ulang (`drawFx`): MONO, DUAL-TONE, PIXELATE, INVERT, SEPIA, BLUR, THERMAL, SKETCH, GLITCH, NEON, GALAXY. **Ganti efek** = PINCH (jempol+telunjuk bersentuhan, `pinchOf`) — **berarah via `handedness`** (diambil dari `res.handedness[i][0].categoryName`, video TIDAK di-mirror sebelum detect sehingga 'Right' = tangan kanan fisik): kanan = next, kiri = prev (`fxIdx = ((fxIdx+dir)%len+len)%len`), edge trigger `wasPinch` debounce 450ms; portal menguning saat pinch. **Foto area portal** = jempol+kelingking bersentuhan (`photoGestOf`, edge `wasPhoto` debounce 900ms, flash putih 140ms) → `takePortalPhoto(quad,now)` merender ulang konten portal (video mirror + efek aktif, tanpa HUD) ke canvas bbox via transform mirror, lalu `toBlob` + `downloadBlob` ('portal-…png'). **Peace** (`peaceOf`: telunjuk+jari tengah tegak, manis+kelingking turun) = blur seluruh frame; efek portal di-skip saat peace aktif. Filter pixel (DUAL-TONE, THERMAL, SKETCH, NEON) jalan via pipeline `pxProcess` **full-frame, bukan bbox portal** (user minta "efek jalan di portal", tapi hasilnya digambar penuh ke portal di `drawFx` default: `setTransform(1,0,0,1,0,0)` + `drawImage(out, -ox, -oy, w, h)` sehingga menutupi viewport & tak kosong saat portal kecil/besar): `pxFull` = canvas ukuran penuh, di-refresh (video mirror) **setiap frame**, lalu `getImageData` semua piksel → LUT per-pixel (JET colormap, box blur divide α untuk sketch, Sobel ≠0 untuk neon) → `putImageData`. **Throttle SKETCH/NEON 60ms** (`pxFx === fx && now-pxLast < cool` → return cache, dan cache tetap di-draw sehingga anti-kedut & selalu penuh portal). **GALAXY DIHAPUS** — terlalu berat (butuh `ImageSegmenter` + starfield per-frame); `star` canvas & `ensureSeg` ikut dibuang. `draw()` punya guard `video.readyState < 2` (skip frame, cegah crash drawImage). Badge (`camBadge`): jumlah tangan + `EFEK: <nama>` + tag PINCH→/PINCH←/FOTO/PEACE. Efek hanya ada di versi browser. Jangan set `baseOptions.modelAssetPath` via URL berbeda tanpa fallback ke `vendor/`. **Anti-crash:** seluruh body `draw()` dibungkus try/catch (rAF tetap hidup walau ada error), `takePortalPhoto` hanya jalan saat `quad` ada (`if(photo && quad && …)`), `pxBBox` mengembalikan null untuk quad null dan meng-clamp bbox minimal 4px (cegah `TypeError: quad is not iterable` yang dulu membekukan kamera saat peace+thumb-pinky dengan 1 tangan), dan ada guard `video.readyState < 2` di awal `draw()`. GLITCH dibuat halus (2 slice + 1 ghost opacity 0.15) supaya tidak terlihat "double kamera".
- Musik tool: sintesis Web Audio murni (tanpa sample) — **5 instrumen melodi** (dispatcher `voice(midi,vel,dur)` per nilai `instSel`): **Piano** (`playPiano`: osc sine + triangle 2× frekuensi + lowpass + envelope), **Gitar** (`playGitar`: Karplus-Strong — burst noise → **feedback loop 0.96 tanpa filter di loop** (filter lowpass hanya di output) + pluck triangle blend 140ms biar suara dijamin keluar di semua browser, release 2.4s), **Bass** (`playBass`: triangle turun 1 oktaf + sine/2, lowpass 420), **Organ** (`playOrgan`: 2 sawtooth detune 0.5% + square sub, vibrato 5.5Hz, sustain lalu release), **Flute** (`playFlute`: sine + vibrato lewat `vibG` ke `o.frequency`, breath noise bandpass). Keyboard C3–E5 = 37 tuts (baris bawah `zxcvbnm,./` C3–E4, atas `qwertyuiop` C4–E5, hitam `sdghj` & `23567`) dan **Drum** (`playDrum`: kick pitch-drop, snare noise bandpass, hat/crash noise highpass, 3 tom). **Keyboard mapping berbasis `e.code`** (KeyZ/Comma/Digit2 dst — bebas layout, Shift+digit tetap kebaca) dengan **Shift = +1 oktaf** (`SHIFT_MIDI`, sampai E6); keyup melepas kedua varian (`held` polyphony). `renderStage()` membangun UI per instrumen (`.pkey` jika bukan 'drum', `.dpad` jika drum); keydown/keyup global memetakan tombol (skip saat fokus input; `e.repeat` diabaikan), hasil `base + octShift` (Keyboard mapping berbasis `e.code` (KeyZ/Comma/Digit2 dst — bebas layout, Shift+digit tetap kebaca) dengan **Shift = +1 oktaf** (`SHIFT_MIDI`, sampai E6); keyup melepas kedua varian (`held` polyphony), `m = b + octShift`). **Blur-fix keyboard:** `blurFocus()` di `instSel change`, click button/tombol, pointerdown di stage — supaya callback tidak menelan ketukan keyboard setelah user memakai select/input. **Toolbar ala muted.io** (`.musik-top`, panel dark `.panel-dark`): **Volume** (slider → gain `master` — semua instrumen `connect(master)` bukan `a.destination`; dibuat sekali di `ac()`), **Oktaf** (−/+ geser `octShift` ±24, `renderStage()` ulang & label `C3–E5` bergeser; tombol ± juga Shift-note ikut bergeser), **Sustain** (checkbox → `pressNote` pakai dur 2.2s), **Nama Not** (select C/C# | Do/Re | tanpa — `noteName()` menampilkan; Do=SOLFEGE), **Rekam** (`recNotes` array {m,t} dengan `recT0`, tombol jadi merah `rec-on`), **▶ Putar** (playback `voice(midi,0.9,…)` mengikuti selisih `t` antar-not, clamp 30–2000ms; stop di tombol sama; keduanya dimatikan `__musikStop`). Setiap not main (keyboard/playback) memunculkan **`note-chip`** (`noteRise` fade-up) di `.musik-note-row`. **Autoplay (`loadAuto`):** sumber = file (`decodeAudioData`) atau URL; link **YouTube** di-extract (`ytId` → `ytStreamUrl`: fetch halaman via **CORS proxy** allorigins→codetabs → parse JSON robust `extractBalanced()` (scanner kurung kurawal, string-aware) dari `ytInitialPlayerResponse` → fallback `"streamingData"` → `adaptiveFormats` audio bitrate tertinggi → unduh stream via `fetchVia(su, true)` = **direct dulu, lalu proxy** → decode). `AudioBufferSourceNode` → `AnalyserNode` (fftSize 2048) **tanpa koneksi ke destination — audio asli TIDAK diputar** (analyser tetap memproses tanpa output). Loop rAF `tick()`: **melodi** mengikuti nada via `autoCorr` (autokorelasi dua-pass lag 40–700, threshold 0.05 → frekuensi → MIDI terdekat, gate 130ms + RMS), **Drum** mengikuti ketukan (onset RMS naik >1.3×, gate 80ms, pilih pad dari energi pita frekuensi low/mid/high). `stopAuto()` membatalkan source + rAF; diexpose sebagai `window.__musikStop`.
- **Shared YouTube/fetch helpers** ada di TOP-LEVEL script (bukan di IIFE): `PROXIES`, `fetchVia(u,directFirst)` (direct lalu proxy allorigins→codetabs), `extractBalanced`, `ytId`, `ytStreamUrl(id)` — dipakai musik (autoplay), visualizer, dan trip. Jangan duplikasi ke IIFE lagi.
- Editor Video tool (`editor`, panel dark): input <video> tersembunyi + canvas output (rasio preset 9:16/4:5/1:1/4:3/16:9 via `edtRatios`; ukuran = 720 × 720/r atau 720r × 720). **Ukuran custom**: input `edtSizeW/H` + `edtSizeGo` → `customSize=true`, outW/outH dipakai apa adanya, preset mematikan `customSize`. **Auto-track orang**: `PoseLandmarker` (vendor `pose_landmarker.task` — self-hosted seperti hand_landmarker, fallback GCS) dimuat `ensurePose()`; deteksi throttle 80ms di rAF; per orang dihitung bbox (min/max landmark, ~30% over-bbox saat perlu) + **skor aktivitas** (jumlah pergeseran landmark vs frame sebelumnya) + skor kepercayaan. Mode `trackModeEl`: **auto** = paling aktif (fallback paling besar), **big**, **first**; user bisa **kunci ke orang tertentu** via chip `.person-chip` (`lockIdx`). `cropRect()` menghitung crop ber-rasio yang mengikuti pusat bbox dengan **smoothing lerp 0.14** (anti-jerk), crop diperluas bila bbox lebih besar dari crop; tanpa orang → crop tengah, tapi jika `edtSmooth` (hold target) aktif, tambatan `lastTarget`/`lastSeenAt` menahan kamera di posisi terakhir ≤1,5 dtk. Overlay kotak pelacakan opsional (`edtShowBox`), subtitle dibakar ke output. **Overlay teks/logo** digambar di `draw()` setelah subtitle: judul `edtTitle` (atas-tengah, band gelap), teks berjalan `edtMarquee` (scroll `marqOff` proporsional terhadap `dt`×`edtMarqSpd`, kuning di bawah), logo `edtLogo` (posisi `edtLogoPos` tl/tr/bl/br, ukuran `edtLogoSz`, opacity `edtLogoOp`) — semua ikut terbakar di rekaman/render. **Timeline & Trim**: `buildTimeline()` membangun strip thumbnail (seek berurutan, `tlBusy` batal saat ganti video; klik thumb → `playFrom`), playhead `#edtHead` disinkronkan di `seekPlayhead()` (dipanggil tiap `draw()`), marker A/B (`edtMarkA/B`) bisa digeser (fraction `tlFracA/B`, clamp A<B) → `trimEl` batasi putar/rekaman loop ke A–B (`loop()` seek kembali ke A saat lewat B) dan `edtRender` render hanya rentang A–B; `edtTrimGo` menyalin A–B ke slider Clip Tool; `edtTrimInfo` toggle zona hijau (`.edt-trimz`); segmen klip penting muncul sebagai `.edt-seg` kuning di timeline. **Subtitle**: SpeechRecognition (Chrome/Edge) dari mikrofon, `subFinal`+interim, baris di-wrap 42 char max 3 baris, posisi atas/bawah + ukuran + latar gelap — karena digambar ke canvas tiap frame, terbakar di rekaman. **Audio**: `MediaElementSource` → Analyser(512) → destination; `ctx` di-`close()` saat ganti video (MediaElementSource terikat elemen — elemen video dibuat ulang via `freshVideo()`), dibuat ulang di `setupAudio()`; resume butuh gestur (klik canvas/rekam). **Reduksi Noise (AI Audio)**: `AudioWorkletNode` `nc-reduce` (blob `NC_WORKLET` = spektral subtraction WOLA: FFT radix-2 1024, hop 512, Hann, kurangi profil noise × `coef`, floor 0.06) — `meSrc` di-`connect(ncNode)→ncDest(MediaStreamDestination)` paralel dengan analyser sehingga **audio asli tetap normal**, hanya track rekaman yang diambil dari `ncDest.stream` saat `ncEl` aktif. `edtNcCal` kirim `{cmd:'calibrate'}`: worklet merata-rata 43 frame (~2 dtk) jadi profil `noise`; `edtNcStr` (0.3–9) → `coef=v*0.12`. `ncNode` dibersihkan di `stopAll`. **Rekam**: `canvas.captureStream(30)` + audio track dari `videoEl.captureStream()` (atau `ncDest.stream` saat NC aktif) → MediaRecorder webm (vp9→vp8→polos). **Ekspor tanpa rekam**: tombol `edtRender` (⬇ Unduh Hasil) — `videoEl.currentTime=rA` (0 atau A-trim) + `muted` (captureStream audio tetap jalan walau muted), `fRecord()` + `play()`, interval 250ms menampilkan %, await saat `currentTime>=rB`/`ended` → `stopRecorder()` → download otomatis (`rendering` guard; `__editorStop` tetap aman saat render). **Klip penting**: saat rekam, tiap frame `energyLog.push({t, rms})` (RMS frekuensi 0..1); setelah stop `buildClips()`: threshold `0.22+(1-sens/100)*0.45` (min 0.06), run ≥2.5s, pra/pasca slider, gap <3s digabung → daftar segmen → tombol `edtClips` memakai `ensureFfmpeg()` untuk `-ss -t` tiap segmen → `libvpx+libopus` webm per klip (download berurutan), segmen juga digambar sebagai `.edt-seg` di timeline. Keluar tool → `__editorStop` (finalisasi rekaman & unduh).
- Visualizer pakai **engine studio** `buildStudio('viz', {draw})` (IIFE nomor 9): kontrol sumber (file/URL/YouTube via helper global/mikrofon), AudioContext + Analyser(2048), gain 0.92 → destination (**audio KEDENGAR**, beda dengan musik autoplay yang mute), loop rAF, `canvas.captureStream(30)` → MediaRecorder webm, snapshot PNG, badge nama sumber, `window.__VizStop` = stopAll (stop source/analyser/mic/recorder + clear). **Ekspor 1-klik**: tombol `el.exp` (⬇ Unduh Hasil) = mulai rekam via `toggleRec()` + `setTimeout` stop 12 dtk → onstop otomatis download (butuh sumber audio aktif; selain itu rekam manual `el.rec`/PNG `el.snap` tetap ada). **Visualizer** (`viz`): mode bars/barsMid (mirror)/radial/wave/orbit; custom: jumlah batang 16–128, sensitivitas 30–300%, 2 warna (A/B) atau putaran pelangi (`vizCol` → hsl/rgb mix), latar gelap/trail bening, cermin.
- **Trip Replay** tool (`trip`, panel terang, IIFE nomor 10 — **bukan** engine studio; gaya tunnel/plasma DIHAPUS): peta **Leaflet 1.9.4** (cdnjs) dimuat lazy via `loadLeaflet()` saat panel dibuka — hook `window.__tripShow` dipanggil dari `showToolHooks(key)` → `initMap()` (OSM tiles) + `invalidateSize()`; `window.__tripStop` = hentikan animasi (dipanggil `hideToolHooks` saat pindah tool). Asal/tujuan: input teks → geocode **Nominatim** (`fetchVia` direct-first; ke-2-nya paralel `Promise.all`, isi `aEl`/`bEl` dengan lat,lng) atau klik peta (`map.on('click')` — klik 1 = asal, klik 2 = tujuan + langsung `runRoute()`); marker `L.circleMarker` merah (asal) / hijau (tujuan) via `setPt('A'|'B', lat, lng)`. Rute: **OSRM public** `router.project-osrm.org/route/v1/driving/{lon,lat};{lon,lat}?overview=full&geometries=geojson` (`ptA/ptB` = [lat,lng]). **Kendaraan** (`VEHICLES`, pilih `tripVehicle`): mobil/bus/motor/pesawat — **SVG top-down "3D" inline** (shadow, gradien bodi, kaca, roda; `vehImg()` render ke Image via data-URL untuk dipakai juga di canvas render), marker `L.divIcon` kelas kosong + div `.veh3d` (rotasi `carEl.style.transform`, nekal `#tripMap .leaflet-div-icon{background:none;border:none}`); kecepatan relatif kendaraan (`veh().speed` dikali `relDur()`), pesawat = **great-circle** `gcircleSamples(600)` (slerp bola) + polyline putus biru, bukan rute jalan. **Smoothing**: rute di-`resample(600)` → Catmull-Rom `posAt(f)` (heading dari turunan spline), `hSmooth` di-lerp sudut 0.16/frame (anti-jerk), easing `ease` (cosine in-out) untuk mobil/bus/motor (pesawat linear). Playback: `animDur = clamp(routeDur*spd, 12, 240)`s (`spd` 0.35 untuk pesawat), poster di slider `#tripProg`, kecepatan 0.5×–8×, ⇄ tukar. **Ekspor tanpa rekam**: `tripVid` (⬇ Unduh Video) = render 12 dtk 1280×720@30fps — tile di-`fetch`+`createImageBitmap` (cache `tileCache`/`tileImg`, preload semua tile jalur dulu), draw manual ke canvas offscreen via proyeksi `L.CRS.EPSG3857` (jalur tempuh oranye + sisa putih, pin A/B, atribusi ©, kendaraan di-`drawImage` rotasi) → `captureStream` + MediaRecorder webm → `downloadBlob('trip-replay.webm')`; `tripSnap` = PNG frame sama. `__tripStop` hentikan animasi. CDN: Leaflet CSS+JS lazy via `<link>`/`<script>` (bukan ESM).
- Proteksi File tool (`protect`): **format `.plock`** biner kustom — `PLOCK1` + u32 versi(1) + salt 16B + iv 12B + note + jumlah file + per-file (nama u32-len, size u64) + ciphertext. Enkripsi **AES-256-GCM** WebCrypto, key dari **PBKDF2-SHA256 310.000 iterasi**, salt/iv acak per file; password TIDAK disimpan. File input multiple → di-`zip` dulu (JSZip lazy dari cdnjs 3.10.1). Buka: parse binary → decrypt (GCM gagal = "Password salah") → list isi zip → unduh per file / preview gambar-audio-video inline / Unduh Semua (zip mentah hasil decrypt). Struktur baca pakai `DataView` little-endian (`readU32/readU64`).
- External CDN deps (all lazy except the first two):
  - eager: Google Fonts, `qrcode-generator` 1.4.4 (cdnjs, replaces old qrcodejs — the QR panel renders canvas/SVG itself from `qr.isDark()`).
  - lazy: `@ffmpeg/ffmpeg@0.12.10` esm + `@ffmpeg/core@0.12.6` esm (single-thread build, works on GitHub Pages WITHOUT COOP/COEP headers), `pdf-lib@1.17.1`, `gif.js` 0.2.0 (cdnjs, worker loaded via text-fetch + blob), `jszip@3.10.1` (lazy, dipakai panel protect saja). MediaPipe tasks-vision TIDAK lewat CDN — self-hosted (lihat bagian webcam; vendor juga berisi `pose_landmarker.task` untuk editor video).
- FFmpeg integration gotchas (rarely obvious, hard-won):
  - Old API (`@ffmpeg/ffmpeg@0.11.x` + createFFmpeg, and `@ffmpeg/core@0.11.x`) is BROKEN on static hosts — the pthread core requires SharedArrayBuffer (needs COOP/COEP headers GitHub Pages can't set).
  - Working combo: dynamic `import()` of 0.12.10 ESM + blob module-worker (worker.js text-fetched, its `"./const.js"`/`"./errors.js"` imports rewritten to absolute CDN URLs) + `classWorkerURL` load option + esm core. See `ensureFfmpeg()`.
  - `file://` MUST be blocked before loading ffmpeg (raise `FILE_ONLY`) — worker spawn under null origin crashes the renderer tab.
  - New API has no `FS('stat')` — target-size search checks sizes via `readFile(...).length`.
- Verify changes by opening the file in a browser. `file://` covers everything except media conversion (needs http(s)/localhost).

## Vercel (opsional, siap pakai)

- `vercel.json` menyetel `Cross-Origin-Opener-Policy: same-origin` + `Cross-Origin-Embedder-Policy: credentialless` → SharedArrayBuffer tersedia (ffmpeg core multithread bisa dipakai). Semua CDN yang dipakai sudah mengirim `CORP: cross-origin`, jadi aman.
- Site tetap bekerja tanpa Vercel — ffmpeg memakai core single-thread yang jalan di GitHub Pages tanpa header. Jangan ubah mekanisme `ensureFfmpeg()` agar tetap universal.
